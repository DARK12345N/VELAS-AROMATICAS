# 🕯️ Velas Aromáticas - Tienda Online

Una página web moderna y elegante para la venta de velas aromáticas artesanales. Desarrollada con HTML5, CSS3 y JavaScript vanilla, ofrece una experiencia de usuario excepcional con diseño responsivo y funcionalidades interactivas.

## ✨ Características Principales

### 🎨 Diseño Moderno
- **Interfaz elegante** con colores cálidos inspirados en las velas
- **Diseño responsivo** que se adapta a todos los dispositivos
- **Animaciones suaves** y transiciones fluidas
- **Tipografía moderna** con Google Fonts (Poppins)

### 🛍️ Funcionalidades de E-commerce
- **Catálogo de productos** con 8 velas aromáticas diferentes
- **Sistema de filtrado** por categorías (Floral, Cítricos, Maderas, Vainilla)
- **Búsqueda de productos** en tiempo real
- **Carrito de compras** con persistencia en localStorage
- **Modal de detalles** de productos con información completa
- **Descarga de comprobante PDF** desde el carrito

### 📱 Experiencia de Usuario
- **Navegación suave** con scroll automático
- **Menú hamburguesa** para dispositivos móviles
- **Formulario de contacto** funcional
- **Mensajes de éxito/error** para feedback del usuario
- **Soporte para teclado** (ESC para cerrar modales)

## 🚀 Tecnologías Utilizadas

- **HTML5** - Estructura semántica y accesible
- **CSS3** - Estilos modernos con Flexbox y Grid
- **JavaScript ES6+** - Funcionalidades interactivas
- **Font Awesome** - Iconografía profesional
- **Google Fonts** - Tipografía elegante

## 📱 Responsive Design

La página está optimizada para:
- **Desktop** (1200px+)
- **Tablet** (768px - 1199px)
- **Mobile** (320px - 767px)

### Breakpoints principales:
- `768px` - Cambio a menú hamburguesa
- `480px` - Optimización para móviles pequeños

## 🚀 Cómo Usar

1. **Abrir el archivo** `index.html` en cualquier navegador moderno
2. **Navegar** por las diferentes secciones usando el menú
3. **Explorar productos** usando los filtros y búsqueda
4. **Agregar productos** al carrito haciendo clic en "Agregar al Carrito"
5. **Ver detalles** haciendo clic en cualquier producto
6. **Completar compra** desde el carrito de compras
7. **Descargar el pedido** en PDF desde el carrito
8. **Contactar** usando el formulario de contacto
